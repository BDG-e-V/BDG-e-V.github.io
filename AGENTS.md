# AGENTS.md

Official website for **BDG e. V.** (Berlin Developer Group), a German registered non-profit association (Amtsgericht Charlottenburg, VR 42836 B).

## Key Principles

- **Pure Static Site (No Build Step):** Plain HTML and `main.css` only. No JavaScript, frameworks, bundlers, or package managers. Pushing to `main` deploys the repo root directly to GitHub Pages.
- **90s Web Aesthetic:** Deliberately retro, text-first styling—light mode (`#ffffff` bg, `#000000` text), Times New Roman / serif, classic link colors (`#0000ff` / `#800080` / `#ff0000`), `<hr>` dividers, and bracketed text nav (`[ Link ] | [ Link ]`) in an 800px centered column. Do not modernize the UI or add CSS frameworks/JS unless explicitly asked.
- **Legal Content:** `impressum.html` (§ 5 DDG) and `satzung.html` (German articles of association) contain legally required/binding text—do not alter legal wording or German text casually.
